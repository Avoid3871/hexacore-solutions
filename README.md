## 🚀 Features & Highlights

1. **Brutales Schwarz-Weiß Design & Typewriter-Typografie**:
   - `Courier Prime` und `Space Mono` Typewriter-Schriftarten mit blinkendem Terminal-Cursor `█`.
   - Reines Monochrom (Schwarz #000000, Tiefschwarz #0a0a0a, Reinweiß #ffffff).
   - Authentische mechanische Typewriter-Sound-Synthese über die native Web Audio API (keine externen Audio-Dateien nötig, umschaltbar über `[AUDIO: ON/OFF]`).

2. **Interaktive 3D ASCII Engine (`AsciiCanvas3D`)**:
   - Echtes mathematisches 3D-Wireframe Rendering im Browser (60 FPS).
   - Modelle: `⬢ Hexacore 3D`, `Torus (Donut)`, `Cube`, `Sphere`.
   - Mit der Maus per Drag & Drop in 3D rotierbar.
   - Umschaltbare Zeichen-Dichten (Klassisch `.:-=+*#%@`, Blöcke ` ░▒▓█`, Binär ` 01`, Hex).

3. **Interaktiver Projekt- & Lösungs-Kalkulator**:
   - Schrittweise Berechnung von High-End Websites, Headless E-Commerce und Web-Applikationen.
   - Wählbare Zusatzmodule (ASCII 3D Visuals, CMS, Stripe Payment, CRM Sync, etc.).
   - Generiert automatisch ein Terminal-ASCII-Manifest mit Preisspanne und Entwicklungsdauer.
   - Ein Klick überträgt die Spezifikation direkt in das Anfrageformular!

4. **ASCII-Lab & Echtzeit-Generator**:
   - Besucher können beliebigen Text oder Markennamen eintippen und in ASCII-Art konvertieren.
   - Live mathematische ASCII Sine-Wave Wellenfeld-Animation.
   - 1-Klick-Kopierfunktion mit Konfetti-Effekt.

5. **Ausgewählte Case Studies & Referenzen**:
   - Umschaltbar zwischen Minimal-Code und ASCII-Wireframe-Ansicht.
   - Detaillierte Modals zu Problem, maßgeschneiderter Lösung und messbarem ROI.

6. **Terminal-Anfrageformular**:
   - Validierung, Ticket-Generierung (`TICKET_#HEXA-XXXXXX`), DSGVO-konforme Datenschutzerklärung und Impressum.

- **Framework**: React 18 & TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Sound**: Web Audio API (Synthetische mechanische Klicks & Glocke)
- **Effekte**: Canvas Confetti & Custom ASCII Shaders
